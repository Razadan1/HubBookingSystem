# HubBookingSystem

## 📌 Overview
HubBookingSystem is a web application designed to streamline the booking of working spaces. It allows users to browse available spaces, make reservations, and manage bookings with ease.

## 🚀 Features
- User authentication (Sign up, Login, Logout)
- Browse available working spaces
- Real-time booking system
- Booking history and management
- Payment integration (if applicable)
- Admin dashboard for managing spaces and bookings

## 🛠️ Technologies Used
- **Frontend:** HTML, Bootstrap, JavaScript
- **Backend:** C#, MVC, ASP.NET Core
- **Database:** MySQL
- **Authentication:** Identity Framework Core
- **Deployment:** Netlify

## 🌐 Usage
1. Sign up or log in
2. Browse available workspaces
3. Select a date and time for booking
4. Confirm the reservation
5. Manage bookings from your dashboard

## 📖 API Endpoints (Example)
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/auth/register` | Register a new user |
| POST | `/api/auth/login` | Login user |
| GET | `/api/workspaces` | Get available workspaces |
| POST | `/api/bookings` | Create a new booking |
| GET | `/api/bookings/:id` | Get booking details |
